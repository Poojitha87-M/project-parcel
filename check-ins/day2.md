# Day 2 Check-in – Project Parcel

## Objective
Train and evaluate machine learning models.

## Work Completed
- Prepared numerical and categorical features.
- Used One-Hot Encoding and StandardScaler.
- Applied a chronological 80:20 train-test split.
- Trained Logistic Regression and Random Forest models.
- Compared accuracy, precision, recall and F1-score.
- Generated confusion matrices.

## Key Learning
Accuracy alone is not enough. Recall is important because missing a late shipment can affect customers and operations.

## Findings
Logistic Regression performed better than Random Forest on the test data. However, late-shipment recall was low and requires improvement.

## Limitation
The demonstration dataset is synthetic, so these results do not represent real-world model performance.
